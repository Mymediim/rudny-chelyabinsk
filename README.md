# Рудный–Челябинск

Интерактивный прототип пассажирского приложения на русском и казахском языках.

Сценарии: расписание, выбор рейса, оформление, демонстрационная оплата Kaspi / СБП, сохранение и просмотр билетов. Все цены и рейсы учебные. Реальные платежи и отправка данных отсутствуют. Билеты хранятся в localStorage браузера; для проверки используйте вымышленные данные.

GitHub Pages: публикация ветки `main`, папка `/`, по аналогии с `Mymediim/troutbox-prototype`.

Локальный запуск: `python -m http.server 8080`, затем открыть `http://localhost:8080`.
